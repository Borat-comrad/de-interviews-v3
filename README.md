# Аналитика тарифов грузоперевозок

PostgreSQL 17 хранит исходный снимок `raw`, очищенные сделки `core`, карточки
маршрутов и прогнозы `mart`. Python запускает пакетные SQL-преобразования;
CatBoost обучается на прошлом периоде и оценивает тестовые и будущие заявки.

## Решение

- Загрузка по полуоткрытому окну `loading_date`: `[start_date, end_date)`.
- Повторная загрузка атомарно заменяет окно, включая карантин и связи.
- Город выбирается по минимальному `cities.id`, кузова — по стандартной группе.
- Курс берётся строго по `nearest_rate_date`; отсутствующий курс — карантин.
- Витрина использует месяцы `price_dates`, не только месяц погрузки.
- ML: один пример на сделку, явный список признаков, временной split на 2026-10-05.
- Бонусные Airflow, Superset и ClickHouse не используются: обязательную задачу
  решают SQL, Python и один PostgreSQL без дополнительной инфраструктуры.

Исходные `sql/schema.sql` и `sql/synthetic.sql` сохранены из задания без изменений.
